ABOUT THE JOURNAL

每個數字背後，都有一個人。

Beyond the Court｜場上場下，是一個從勇士隊開始的籃球人物與數據專題。

為什麼做這個網站？

球迷記得一場比賽的得分，也會記得球員送給媽媽的驚喜、回到家鄉的公益，或在另一項運動裡的熱情。我們把這些入口放在一起，讓認識一支球隊變得更完整。

讓下一次擴充，有章可循。

本專案的核心是 AGENTS.md：它定義頁面結構、視覺、資料格式、來源政策與完成檢查。新增球員不需重做頁面；新增故事不需到各個頁面貼卡片。共用模板依照人物 ID 與資料關聯，自動產生連結。

已實際示範的延伸

第一版包含名單中的 18 位球員、全體逐季生涯表與 20 篇故事；Curry 的公益、高爾夫與品牌合作，使用同一套故事格式分別建立，再自動匯入個人頁。這套結構可延伸到其他球員與球隊。

專案方式

使用 Python 標準函式庫產生靜態網頁，搭配原生 HTML、CSS 與 JavaScript。無第三方套件、無資料庫、無登入需求，產出的 dist 資料夾可部署至 GitHub Pages 等靜態服務。

這是非官方球迷與課堂作品，與 NBA、球隊、球員及品牌無隸屬或背書關係。數據來源、快照範圍及圖片說明請見 資料來源與更新。
