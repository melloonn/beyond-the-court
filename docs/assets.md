# 素材來源與使用說明

## 球員頭像
18 位球員頭像來自 ESPN 名單的公開 `headshot.href`，下載為 `public/images/players/<ESPN ID>.png`。每位球員 JSON 中的 `headshotSource` 保留原始網址。

用於非商業課堂作品中的球員識別與人物介紹。圖片著作權歸 ESPN、NBA 或各原權利人，下載不代表已取得開放授權；本專案不擁有、不再授權第三方圖片。如將作品轉作商業用途，需另行確認圖片使用權，或改用已取得授權的素材。

## 自製圖形與版面
favicon 籃球 SVG、球場線條、背號構圖、故事卡片與配色為本專案程式繪製，沒有下載其他網站的版面或截圖。

## 字體
介面提供系統字體 fallback，中文優先可用的 Noto Sans TC／PingFang TC 等字體；英文標題採 Barlow Condensed，內文 DM Sans。英文字體下載自 Google Fonts，採本機託管，不需連接外部字體服務；SIL Open Font License 文件保留於 `src/assets/fonts/`。
